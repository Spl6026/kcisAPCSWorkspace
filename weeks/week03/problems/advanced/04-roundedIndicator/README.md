# 04 模型指標取整

難度：進階

## 題目說明

分析報表使用指標 (b² − 4ac) / 7。報表只接受整數，請將計算結果四捨五入取到最接近的整數。

## 輸入格式

一行三個整數 a、b、c。

## 輸出格式

輸出四捨五入取整後的整數指標。

## 資料範圍

−1000 ≤ a、b、c ≤ 1000，且保證 b² − 4ac ≥ 0（計算結果大於等於 0）。

## 補充說明

數學式的 b² 表示 b 乘上 b；C++ 的 ^ 並不表示次方。

## 範例 1

### 輸入

```text
2 4 1
```

### 輸出

```text
1
```

## 範例 2

### 輸入

```text
1 6 1
```

### 輸出

```text
5
```

## 範例說明

第一例為 (16 − 8) / 7 = 8 / 7 ≈ 1.14，四捨五入後為 1；第二例為 (36 − 4) / 7 = 32 / 7 ≈ 4.57，四捨五入後為 5。

## 可選提示

<details>
<summary>提示：浮點數四捨五入到整數的技巧</summary>

對於非負的浮點數，將數值**加上 0.5 後再轉為整數**（例如 `(int)(value + 0.5)`），就能巧妙達成四捨五入的效果！
- `1.14 + 0.5 = 1.64`，轉為整數截斷後為 `1`（捨去）
- `4.57 + 0.5 = 5.07`，轉為整數截斷後為 `5`（進位）
- `3.50 + 0.5 = 4.00`，轉為整數截斷後為 `4`（四捨五入）

</details>
