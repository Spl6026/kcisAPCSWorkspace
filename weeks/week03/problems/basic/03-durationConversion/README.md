# 03 紀錄時間換算

難度：基礎

## 題目說明

設備紀錄以秒儲存執行時間，排程表則以分鐘儲存工期。請分別轉換這兩筆時間。

## 輸入格式

第一行是一個整數 s，表示執行秒數。第二行是三個整數 d、h、m，表示天、小時、分鐘。

## 輸出格式

第一行把 s 換成 Hhr Mmin Ssec；分鐘與秒數均在 0～59，數字不補零。第二行輸出 d 天 h 小時 m 分鐘共有幾分鐘。

## 資料範圍

0 ≤ s ≤ 1000000000；0 ≤ d ≤ 100000；0 ≤ h ≤ 23；0 ≤ m ≤ 59。

## 範例

### 輸入

```text
400
0 1 2
```

### 輸出

```text
0hr 6min 40sec
62
```

## 範例說明

400 秒是 6 分 40 秒；1 小時 2 分鐘共有 62 分鐘。

## 可選提示

一小時有 3600 秒。先用 `s / 3600` 取得完整小時，再用 `s % 3600` 留下不足一小時的秒數；對剩餘秒數重複相同想法即可取得分鐘與秒數。
