# 01 雙件包裝檢查

難度：基礎

## 題目說明

一批零件要以每包兩件的方式包裝。判斷是否能全部裝完而沒有剩下單件。

## 輸入格式

輸入一個整數 n，表示零件數量。

## 輸出格式

可以剛好包完輸出 1，否則輸出 0。

## 資料範圍

0 ≤ n ≤ 1000000000；零件數為 0 時視為可以包完。

## 範例 1

### 輸入

```text
20
```

### 輸出

```text
1
```

## 範例 2

### 輸入

```text
7
```

### 輸出

```text
0
```

## 範例說明

20 件可分成 10 包；7 件會剩下 1 件。
