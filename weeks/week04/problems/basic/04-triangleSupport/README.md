# 04 三角支架檢查

難度：基礎

## 題目說明

工廠取得三支直桿，要確認能否接成一個非退化三角形支架。任意兩邊的長度和都必須大於第三邊。

## 輸入格式

一行三個整數 a、b、c，表示桿長。

## 輸出格式

能形成三角形輸出 YES，否則輸出 NO。

## 資料範圍

1 ≤ a、b、c ≤ 1000000；允許等長。

## 範例 1

### 輸入

```text
3 4 5
```

### 輸出

```text
YES
```

## 範例 2

### 輸入

```text
1 1 2
```

### 輸出

```text
NO
```

## 範例說明

1 + 1 等於 2，只能排成直線，不能形成三角形。
