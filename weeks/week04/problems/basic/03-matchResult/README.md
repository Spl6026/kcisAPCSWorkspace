# 03 對戰結果判定

難度：基礎

## 題目說明

對戰紀錄用 c 表示剪刀、t 表示石頭、p 表示布。石頭勝剪刀、剪刀勝布、布勝石頭。請判斷第一位參賽者的結果。

## 輸入格式

一行兩個字元，依序表示第一位及第二位參賽者的選擇。

## 輸出格式

第一位獲勝輸出 win，落敗輸出 lose，平手輸出 no winner。

## 資料範圍

輸入只會是 c、t、p。

## 範例 1

### 輸入

```text
c t
```

### 輸出

```text
lose
```

## 範例 2

### 輸入

```text
p p
```

### 輸出

```text
no winner
```

## 範例說明

第一例剪刀輸給石頭；第二例兩人選擇相同。
