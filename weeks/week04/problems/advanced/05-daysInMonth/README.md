# 05 排程月份天數

難度：進階

## 題目說明

排程系統需要知道指定月份可排幾天。公曆閏年規則為：可被 400 整除，或可被 4 整除但不能被 100 整除。閏年二月有 29 天，其餘年份二月有 28 天。

## 輸入格式

一行兩個整數 y、m，表示年份與月份。

## 輸出格式

輸出該月份的天數。

## 資料範圍

1 ≤ y ≤ 9999；1 ≤ m ≤ 12。

## 範例 1

### 輸入

```text
2000 2
```

### 輸出

```text
29
```

## 範例 2

### 輸入

```text
1900 2
```

### 輸出

```text
28
```

## 範例說明

2000 可被 400 整除；1900 可被 100 整除但不能被 400 整除。
